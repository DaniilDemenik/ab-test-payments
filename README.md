# A/B-тест: Новая форма оплаты ЖКХ

**О проекте:** Анализ результатов 30-дневного A/B-теста новой формы оплаты с автозаполнением реквизитов (Группа B) против старой формы (Группа A). 

**Задача:** Оценить, увеличивает ли новая механика долю успешных оплат, и дать рекомендацию продуктовой команде.

** Стек:** Python (pandas, numpy), статистический анализ (statsmodels), визуализация (matplotlib).

---

###  Подготовка данных
Перед анализом проведена очистка от аномалий, чтобы не исказить метрики: удалены профили с некорректным возрастом и пустым городом, отфильтрованы платежи с несуществующими `user_id` и несовпадением групп. Итоговая выборка: 1500 пользователей и 2658 платежей.

###  Ключевые результаты
*   **Конверсия в успешную оплату:** 
    *   Группа A (старая форма): **49.73%**
    *   Группа B (новая форма): **64.40%** (+14.67 п.п.)
*   **Статистическая значимость:** Односторонний Z-тест для пропорций показал **p-value < 0.001** (разница не случайна).
*   **Рекомендация:** Запустить новую форму на 100% пользователей, так как она значимо снижает отвал на этапе ввода данных.
